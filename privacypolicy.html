Privacy Policy — BloxBreak!

Developer: rovenkodev ("we", "us", "our")

Application: BloxBreak!: Daily Challange ("the app")

Last updated: October 16, 2026

1. What the app does

BloxBreak! is an offline-playable 8×8 block puzzle game. The app does not require an account, registration or email. All game data (score, preferences) is stored only on your device. The only network activity is ad requests to Google's AdMob service.

2. Data we collect locally (never transmitted)

Stored in the device's local storage (Android SharedPreferences, not synced to any server):

  • Best score and run statistics (score, combo streak, daily challenge progress).
  • Sound on/off and vibration on/off preferences (chosen by you).
  • Daily challenge salt and progress (a per-install random token used to generate a local per-day set of goals; never uploaded).
  • In-progress run snapshot (so you can resume a run after closing).

None of this data leaves your device.

3. Permission usage

  • VIBRATE — only used to vibrate the device when enabled in the in-app settings. Never used in the background.
  • Network (INTERNET/ACCESS_NETWORK_STATE) — required by the ad SDK for ad delivery.
  • No camera, microphone, contacts, location, storage or other sensitive permissions are requested.

4. Third-party services — Google AdMob

BloxBreak! uses Google Mobile Ads (AdMob) to display a banner ad at the bottom of the screen. AdMob may collect, process or use:

  • Advertising ID (AAID) — only in development builds that are registered as test devices use test ads; release builds use the real ad unit ca-app-pub-1555784587312566/6943089898.
  • IP address, device model, OS version, language, timezone.
  • Coarse / approximate location inferred from IP address.
  • App-interaction metrics for ad delivery, fraud prevention and measurement.

Please review Google's privacy policy for full details: https://policies.google.com/privacy

5. Consent (EEA / UK / US states)

The AdMob plugin ships Google's User Messaging Platform (UMP) for consent collection in regulated regions. As of v1.0, U (region-attested) consent is not yet wired; the release build uses the default consent flow. We are evaluating integrating GoogleMobileAds.Ump before wider rollout.

If you are in the EEA/UK and want to manage your choices, please contact us (below) until UMP is integrated. Ad networks serving in these regions will still abide by their own consent framework.

6. Children

BloxBreak! is not directed to children under 13 (specifically not designed for the "Families" / "Teacher Approved" programs). Ads are served under the standard app category "Puzzle (Game)". If a parent believes their child's data was collected in error, contact us and we'll delete it (only local storage — no server record exists).

7. Data deletion / retention

  • All locally-stored data can be cleared by uninstalling the app or clearing app storage in Android Settings → Apps → BloxBreak! → Storage → Clear data.
  • No account or server-side data is retained.
  • AdMob retains data per Google's own policy (see section 4).

8. Changes

We may update this policy as the app evolves; the "Last updated" date will be updated. Material changes will be communicated through an updated release.
